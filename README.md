GxGeo Reloaded R24
Emulataeur Neo Geo pour Nintendo Wii

L'expérience Neo Geo sur Nintendo Wii

GxGeo Reloaded est une version améliorée de l'émulateur GxGeo pour Nintendo Wii. Ce projet a pour objectif de moderniser l'interface, d'améliorer le confort d'utilisation et de faire évoluer l'expérience de jeu.

───

Présentation

GxGeo Reloaded reprend les bases de l'émulateur GxGeo original et propose une interface retravaillée ainsi que différentes améliorations.

Le projet est développé avec une attention particulière portée à la simplicité d'utilisation, à la navigation et à l'affichage des jeux.

Fonctionnalités

• Interface graphique améliorée
• Menu de sélection des jeux retravaillé
• Navigation optimisée
• prise en charge du port Usb pour les roms
• Gestion sauvegarde partie jeu en cours
• Prise en charge supérieur à 25 Mo
• Gestion des favoris
• Affichage adapté à la Nintendo Wii
• Paramétrage des boutons manettes

Installation

1. Télécharger la dernière version.
2. Extraire le contenu de l'archive ZIP.
3. Copier le dossier "apps" à la racine de la carte SD.
4. Copier le répertoire GxGeo-Reloaded à la racine de la carte SD.
5. Lancer GxGeo Reloaded depuis Homebrew Channel.

Téléchargement

Les versions officielles seront disponibles dans la rubrique Releases de ce dépôt.
